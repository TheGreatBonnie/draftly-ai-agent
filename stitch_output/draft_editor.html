API Rate Limiting & Quotas

Guidelines and thresholds for managing request density on the Draftly Public API.

speed Standard Limits

To ensure system stability, all API requests are governed by a sliding-window rate limiting algorithm. Limits are applied per API Key.

  • check_circle Threshold: 1,000 requests / minute
  • check_circle Algorithm: Sliding Window Log
  • check_circle Error Code: 429 Too Many Requests

Response Headers

Each response includes headers indicating your current usage. Note: Headers are case-insensitive. 

# Example Response Headers
HTTP/1.1 200 OK
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 942
X-RateLimit-Reset: 1625097600

Introduction to Draftly Engine

Draftly Engine is a high-performance orchestration layer designed to transform raw technical specifications into production-ready documentation. Built with the Digital Loom metaphor in mind, it weaves together your code, metadata, and design system tokens to create unified, beautiful end-user portals in real-time.

Getting Started

To begin weaving your documentation, you'll need to install the Draftly CLI and authenticate your workspace.

bash — install.sh 
# Install the Draftly CLI
npm install -g @draftly/cli

# Initialize your project
draftly init --template loom-modern

# Start the orchestration engine
draftly weave --watch

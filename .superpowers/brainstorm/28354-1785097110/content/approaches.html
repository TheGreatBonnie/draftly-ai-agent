How to fix CORS errors in production

troubleshooting v2 · Published Jul 24, 2026

CORS errors happen when the server doesn't include the correct Access-Control-Allow-Origin header.

Common causes:

  • Missing header in production config
  • Wildcard (*) not allowed with credentials
  • Preflight requests timing out

Pros

  • Best reading experience
  • Familiar to Notion users
  • Simple to implement

Cons

  • No persistent nav while reading
  • Long docs hard to navigate

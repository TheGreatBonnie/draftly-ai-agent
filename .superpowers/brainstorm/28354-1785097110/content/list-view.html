List View Spec

Page title: "Documentation" with subtitle "Browse your AI-generated documentation library."

Filter tabs: All / Published / Pending / Draft / Rejected — each with count. Active tab uses charcoal background.

Search: Text input filtering by document title (case-insensitive). Right-aligned next to tabs.

Cards: Doc type badge + version + relative time · title (bold) · content preview snippet (~120 chars) · status badge + confidence bar (right side).

Click: Entire card is clickable → navigates to detail page.

Empty state: Icon + "No documents match this filter" + suggestion text.

Loading: 3 skeleton cards with pulse animation.

States Spec

Empty (no docs): Document icon + "No documentation yet" + explanation + CTA to connect Slack. Used when the org has zero docs.

Empty (no results): Search icon + "No documents match this filter" + suggestion. Used when filter/search returns nothing.

Loading: 3 skeleton cards with pulse animation. Matches the card layout (badge placeholders, title bar, content bar).

Error: Warning icon + "Failed to load documentation" + Retry button. Clears error and re-fetches on click.

# Getting Started with Draftly

Draftly is an autonomous documentation engineering platform. It watches your support conversations in Slack, Discord, and GitHub — then generates, reviews, and publishes documentation automatically.

## How It Works

Draftly works in three steps:

1. **Connect your channels** — Link Slack, Discord, and GitHub so Draftly can monitor conversations.
2. **AI generates docs** — When a support thread is flagged, Draftly researches, drafts, and evaluates documentation through an 8-stage pipeline.
3. **Review and publish** — You approve, revise, or reject documents via Slack, email, or the dashboard.

## Signing Up

1. Go to [Draftly](/) and click **Get Started**.
2. Create an account using the Clerk authentication flow.
3. Create or join an organization — this is your team's workspace.

## Your First Steps

### 1. Connect an Integration

Head to **Settings** in the sidebar and connect at least one platform:

- **Slack** — Best for teams that handle support in Slack channels
- **Discord** — Great for community-driven support
- **GitHub** — Ideal for issue-driven documentation

See the integration-specific guides for detailed setup instructions.

### 2. Add Knowledge Base Content

The **Knowledge Base** page lets you import existing documentation:

- **URL Import** — Paste a link to a webpage, PDF, Google Doc, or Notion page
- **Manual Upload** — Paste content directly with a title and doc type

The more context you provide, the better Draftly's documentation output will be.

### 3. Generate Your First Documentation

Once an integration is connected and your knowledge base has some content:

1. Post a support question in a connected Slack or Discord channel
2. Mention the Draftly bot or use the configured trigger
3. Draftly will pick up the conversation and start generating documentation
4. Check the **Dashboard** to see the review queue

### 4. Review and Approve

Go to the **Dashboard** to see pending reviews:

- Click **Review** on any card to see the full document
- **Approve** to publish, **Request Changes** to send it back, or **Reject** to discard
- You can also review directly from Slack or email notifications

## Dashboard Overview

| Page | Purpose |
|------|---------|
| Dashboard | Pending review cards with confidence scores |
| Documentation | Browse all generated documents |
| Knowledge Base | Import and manage source documents |
| Memory | Semantic search across your knowledge base |
| Settings | Integrations, team roles, and org config |
| Reviewers | Manage who can review documentation |
